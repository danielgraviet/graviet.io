# Essay Ideas

Use this folder to track blog post ideas before they are ready for `content/posts/`.

## Workflow

1. Create one `.md` file per idea.
2. Start with a strong working title, a slug, and a short summary.
3. Use `status` to track progress:
   - `idea`
   - `outline`
   - `drafting`
   - `ready`
   - `published`
4. Add notes, bullets, source links, partial paragraphs, or a rough outline in the body.
5. When a piece is ready, promote it into `content/posts/` and generate final post metadata there.

## Required Frontmatter

```md
---
title: Why Verification Is the Real Bottleneck for Long-Horizon AI
slug: verification-bottleneck-long-horizon-ai
status: idea
createdAt: 2026-05-12
updatedAt: 2026-05-12
tags: [AI, RL, Verification]
summary: Notes toward an essay on why progress stalls when substeps are hard to verify.
---
```

## Notes For Agents

- Treat files here as working drafts, not published posts.
- Preserve the author's wording and notes unless asked to rewrite.
- Prefer organizing and extending ideas over polishing them prematurely.
- When promoting an idea into `content/posts/`, keep the original substance and create final `title`, `slug`, `excerpt`, `publishedAt`, and `tags`.
